Accessibility

Atmosphere aims to remain comfortable and navigable across input methods, screen sizes, and motion preferences.

Statement updated 18 September 2026

Current approach

  • Keyboard-accessible native controls and visible focus states.
  • Semantic headings, control names, states, and live playback labels.
  • Responsive layouts with scalable text and touch-sized controls.
  • Reduced-motion behavior when the operating system requests it.
  • Dark overlays and glass surfaces designed to preserve text over moving video.
  • Quiet view and audio-only alternatives for reduced visual or network load.

Known limitations

Some video backgrounds can reduce perceived contrast, picture-in-picture support differs by browser and operating system, and ambient media is experiential rather than speech content that can be fully transcribed. Native WebViews can expose controls differently to assistive technologies.

Send feedback

Open an accessibility issue with the affected page or control, operating system, browser or app version, assistive technology, and expected behavior. Do not include sensitive personal information.

Need an immediate alternative?Try audio-only mode, turn off linked playback, reduce motion in system settings, or use the web version in your preferred browser.
