Preview signing noticeThese builds are not yet backed by commercial Apple or Windows certificates. macOS Gatekeeper or Windows SmartScreen may warn about an unknown developer. Continue only after confirming the file came from the official release page and verifying it below.

Windows installation

Download the `.exe` NSIS installer, open it, and follow the setup prompts. A SmartScreen message is expected for an unsigned preview. Do not bypass a warning for a file from another website.

macOS installation

Choose `aarch64` for M1 or newer Macs and `x86_64` for Intel Macs. Open the `.dmg` and drag Atmosphere to Applications. The ad-hoc signed, non-notarized preview may require System Settings → Privacy & Security → Open Anyway after the first attempt.

Linux installation

Use `.deb` on Debian or Ubuntu, or `.AppImage` on other common x64 distributions. WebKitGTK-compatible system libraries are required.

chmod +x Atmosphere*.AppImage
./Atmosphere*.AppImage

Verify the installer

Download the matching `checksums-*.txt` from the release and compare its SHA-256 digest.

# macOS or Linux
shasum -a 256 Atmosphere_*

# Windows PowerShell
Get-FileHash .\Atmosphere_* -Algorithm SHA256

GitHub build provenance can also be checked with:

gh attestation verify ./Atmosphere_* --repo yessur3808/atmosphere

Prefer the browser?

Open Atmosphere on the web; no installation is required. The current desktop preview uses the same interface and streams its media library from the public HTTPS deployment.
